# 太極拳姿勢評価プログラム 仕様書（v1.1 ドラフト）

制定套路の指導現場で、演者のキーポーズ写真を解析し、要訣に基づいたフィードバックを返す評価プログラムの仕様。v1.0 からの主な改訂は、計測モデルの4分類（構造基準／お手本基準／保持型／変化型）の導入と、预备式を基準点とするセッション毎キャリブレーションの設計。

---

## 1. 目的

制定套路（24式等）の主要な定式（キーポーズ）について、演者の姿勢を要訣単位で評価し、**指導の言葉に翻訳されたフィードバック**として提示する。数値の羅列ではなく「肘がめくれて横を向いています」「骨盤が普段より立てられています」といった、稽古でそのまま使える表現で返すことを最重要の設計方針とする。

## 2. 想定ユーザー・前提条件

| 項目 | 内容 |
|------|------|
| ユーザー | 指導者（教室での個別指導の材料、上達の経過観察）、演者本人（自己点検） |
| 対象套路 | 制定套路（24式等）。規定演技であるため、型の基準値が一意に定まる。 |
| 対象学習者 | **预备式が概ね成立している学習者**。预备式は本プログラムの全評価の基準点であり、これが大きく崩れている段階の学習者は対象外（その段階の指導はプログラム以前の領域）。 |
| 利用環境 | 教室または自宅。Mac 1台＋スマホ/デジカメで完結。写真はローカル処理（クラウド送信なし）。 |

## 3. 計測モデル — 4つの評価タイプ

要訣の性質に応じて、比較の基準が異なる。本プログラムは以下の4タイプを区別する。

| タイプ | 基準 | 評価の意味 | 必要な事前データ |
|--------|------|------------|------------------|
| **A 構造基準** | 幾何学（鉛直線・足の位置等） | 人によらず絶対評価 | なし |
| **B お手本基準** | 制定套路の規定＋先生のお手本 | 型の形の一致度 | お手本写真（複数枚→許容範囲） |
| **C 保持型** | 本人の预备式（＋怒らせ肩） | 基準姿勢を**どれだけ保てたか** | セッション毎キャリブレーション |
| **D 変化型** | 本人の预备式 | 習慣的緊張から**どれだけ緩める方向に動けたか** | セッション毎キャリブレーション |

### 3.1 セッション毎キャリブレーション

C・D の基準となる本人ベースラインは、その日の体調・緊張で揺れるため、**セッション開始時に毎回撮影**する。

- 撮影内容: **预备式（正面・側面・背面）＋わざと肩を怒らせた立位（正面）** の計4枚
- 预备式の役割: C にとっては「保持すべき理想状態」、D にとっては「習慣的緊張を含む出発点」。同じ写真が両方の基準を兼ねる。
- 怒らせ肩の役割: 沈肩の **2点キャリブレーション**（预备式=すくみ率0%、怒らせ=100%）の上端。同時に、预备式との画像上の差が小さすぎる場合は「この撮影条件では沈肩を測れない」と判定する**感度チェック**を兼ねる。
- 品質ゲート: 预备式写真の段階で立身中正等の構造基準が大きく崩れている場合、「ベースラインとして不適格」と警告し、C・D の評価を保留する。

### 3.2 評価タイプごとの判定方法

- **A**: 指標値を固定閾値（仕様に直書き、運用調整可能なパラメータ）と比較。
- **B**: 制定套路の規定値を一次基準とし、先生のお手本複数枚（推奨5枚以上）の平均±2σ を許容範囲とする。範囲内=OK、±2σ超=注意、±4σ超=要修正。
- **C**: 2点キャリブレーション軸上の比率で表示（例: すくみ率15%）。閾値は比率に対して設定。
- **D**: 预备式からの変化量と**方向**を表示。緩める方向への変化を肯定的に、変化なし・逆方向を指摘対象とする。**変化量の大きさの良否（緩めすぎ）は判定せず、経過観察値とする**（行き過ぎの判定は指導者の眼に委ねる旨を表示に明記）。

## 4. 要訣の翻訳表

実現性: ◎=ランドマークで素直に測れる ○=工夫すれば可 △=シルエット解析頼みで要予備実験

### A 構造基準

| 要訣 | 指標 | 評価面 | 実現性 |
|------|------|--------|--------|
| 立身中正 | 体幹軸（肩中点–尻中点）の鉛直からの傾き角 | 正面＋側面 | ◎ |
| 膝不過足尖（弓歩前膝） | 膝が足首鉛直線より前に出ているか | 側面 | ◎ |
| 膝とつま先の向き | 膝の内倒れ（足首–尻線からの内側偏位） | 正面 | ○ |
| 墜肘 | 肘向きの鉛直からの外向き角（§4.1） | ポーズごとに指定 | ◎ |

#### 4.1 墜肘の測定方法

ランドマークに肘頭は存在しないが、肘の向きは幾何学的に復元できる: **肘→肩ベクトルと肘→手首ベクトルの角二等分線の逆方向**が肘頭の向き。これと鉛直下向きの成す角を、体の正中線から離れる側を正として算出する。

- 閾値（仮置き・運用調整パラメータ）: 〜45度=OK / 45〜70度=注意 / 70度〜=要修正（ほぼ水平＝肘が横を向いた状態）
- **肘角度が160度を超える（腕がほぼ伸びている）場合は原理的に測定不能**とし、その旨を表示する。
- 評価面はポーズ依存（腕が前に出るポーズは側面、横に開くポーズは正面）。キーポーズ定義に評価面を含める。
- 擬似3D座標による3D角度は参考値として併記可（z は推定値のため主評価には使わない）。

### B お手本基準

| 要訣 | 指標 | 評価面 | 実現性 |
|------|------|--------|--------|
| 弓歩の後脚（蹬脚） | 後膝の角度 | 側面 | ◎ |
| 屈膝鬆跨（馬歩等の沈み） | 両膝角度＋尻の相対高さ | 正面 | ◎ |
| 虚実分明（重心配分） | 尻中点の両足首間に対する水平位置比 | 側面 | ◎ |
| 歩幅・架式の高さ | 足首間距離／体幹長、尻の高さ | 正面・側面 | ◎ |

### C 保持型

| 要訣 | 指標 | 評価面 | 実現性 |
|------|------|--------|--------|
| 沈肩 | 肩–耳間距離のすくみ率（预备式0% ↔ 怒らせ100%） | 正面 | ◎ |
| 虚領頂勁 | 耳–肩の鉛直整列（頭部前方偏位）の预备式比での保持 | 側面 | ○ |

※ 虚領頂勁は「预备式で効いている」前提（§2 対象学習者）。

### D 変化型

| 要訣 | 指標 | 評価面 | 実現性 |
|------|------|--------|--------|
| 骨盤の立ち（斂臀・尾閭中正） | シルエット腰部くぼみ深さの预备式からの減少量 | 側面 | △ |
| 含胸 | 肩の前方位置／胸部シルエットの变化 | 側面 | △ |
| 抜背（肩甲骨の開き） | 上背部シルエットの幅・丸みの変化 | 背面 | △ |

※ D はすべてセグメンテーションマスク（人物輪郭）解析に依存する。**評価用撮影は体に沿った服（Tシャツ等）で行う**ことを撮影ガイドの必須条件とする（表演服は輪郭を覆い隠すため）。Phase 1.5 で予備実験を行い、判別不能の場合はメッシュ復元系（SMPL系: HMR 2.0 / 4D-Humans 等）への移行を検討する（§11）。

### 対象外の要訣

呼吸・意識・勁の通りなど外形に現れない要訣は対象外。本プログラムは外形チェックの補助具であり、指導者の眼を置き換えない。

## 5. 機能要件

### F1. 撮影ガイド

- 撮影条件チェックリスト: カメラ高さ（腰の高さ）、距離（全身＋足元の余白）、方向（正面/側面/背面）、背景（無地推奨）、**服装（D系評価時は体に沿った服）**。
- 撮影メタ情報（方向・キーポーズ名・演者名・日付・セッションID）を画像と紐づけて記録。

### F2. セッションキャリブレーション

- セッション開始時に预备式3面＋怒らせ肩1枚を登録し、本人ベースラインを算出する。
- 感度チェック: 预备式と怒らせ肩の差が閾値未満なら、沈肩を当該セッション「測定不能」とする。
- 品質ゲート: 预备式が構造基準を大きく外れる場合は警告し、C・D 評価を保留する。

### F3. 姿勢抽出

- 静止画1枚から人物1名の骨格ランドマーク＋セグメンテーションマスクを抽出。
- 複数人が写る場合は画像中央・最大の人物を選択し、選択結果を注釈画像で確認できること。
- 各指標に信頼度を付与し、低信頼の指標は「測定不能」として評価から除外。

### F4. お手本登録（B 基準用）

- キーポーズ × 撮影方向ごとにお手本写真を複数枚登録し、指標ごとの平均・標準偏差・許容範囲を算出・保存。再計算可能。

### F5. 評価

- キーポーズ写真を A〜D の各タイプの方法で判定し、要訣ごとに OK / 注意 / 要修正 / 測定不能 / 未評価 のいずれかを返す。
- 方向を含む表現とし、左右は**演者本人の左右**で表す（画像上の左右と取り違えない）。
- 重み付き総合スコア（経過観察用、絶対評価でない旨を明記）。重みはキーポーズごとに指導者が設定（既定: 立身中正・膝不過足尖・虚実分明を「高」）。
- **相関セルフチェック**: 墜肘（A）と沈肩（C）は身体的に連動する（肘がめくれると肩がすくむ）ため、レポートに並記する。長期的に相関が出ない場合は測定系の異常を疑う手がかりとする。

### F6. フィードバック表示

- 要訣ごとの判定を指導の言葉で表示（付録A）。
- 比較図: 基準（お手本または预备式）と演者の骨格を正規化して重ね描きし、要修正部位を強調。
- Markdown / CSV 書き出し（Obsidian・表計算での管理を想定）。

### F7. 履歴管理

- 演者 × キーポーズごとの評価履歴と、セッション毎ベースラインの履歴を保存。指標の推移を時系列グラフで表示。
- D 系は「变化量の推移」を主表示とする（その日のベースラインとの差分を時系列で見る）。

## 6. 非機能要件

| 項目 | 要件 |
|------|------|
| 動作環境 | Mac（Apple Silicon）、Python 3.12系。ネット接続は初回モデル取得時のみ。 |
| 処理時間 | 1枚あたり数秒以内（教室でその場で見せられる速度）。 |
| プライバシー | 写真・評価データはローカル保存。演者名は表示名（ニックネーム可）。 |
| 操作性 | 第一段階はCLI。セッション開始のキャリブレーション4枚→各演者の撮影、という教室の流れを最小タイプ数で回せること。 |
| データ互換 | 全保存JSONに schema_version。形式変更時は移行手段を提供。 |

## 8. エラー・例外時の挙動

| 状況 | 挙動 |
|------|------|
| 人物を検出できない | 「検出失敗」を明示し撮影ガイド再確認を促す。評価値は出さない。 |
| 指標の信頼度が低い | 当該要訣を「測定不能」とし総合スコアの分母から除外。 |
| 必要な評価面の写真がない | 「未評価」と表示。代替値での推定はしない。 |
| 腕がほぼ伸びている（肘角>160度） | 墜肘を「測定不能（原理的制約）」と表示。 |
| キャリブレーション感度不足 | 当該セッションの沈肩を「測定不能（感度不足）」とし、撮影条件の改善を提案。 |
| 预备式が品質ゲートに不合格 | 警告の上 C・D を保留。A・B のみ評価。 |
| お手本枚数不足（<3枚） | 許容範囲の信頼性低下を警告した上で暫定評価。 |

**誤った数値を黙って出すことを最も避ける。不明なものは不明と表示する。**

## 9. 制約・免責

- 単眼2D推定が基礎。各面の評価はその面への投影に対するもので、体の回旋は直接測定できない。
- D 系（骨盤・含胸・抜背）はシルエット解析の予備実験結果次第であり、測定可能性自体が未確定（§11 Phase 1.5）。
- 評価値は同一撮影条件下の相対比較にのみ意味を持つ。
- 医学的・競技採点的な正確性は保証しない。指導者の眼の補助具である。

## 10. 受け入れ基準（Phase 1）

- 同一人物・同一ポーズ・同条件2回撮影で、要訣判定が一致する（再現性）。
- 意図的に体幹を10度傾けた写真で「立身中正: 要修正」が方向付きで検出される。
- 肘を意図的に水平近くまでめくった写真で「墜肘: 要修正」、肘を下に向けた写真で「OK」が出る。腕を伸ばした写真では「測定不能」が出る。
- 预备式と怒らせ肩の2枚から、すくみ率0%・100%が正しく較正され、中間的なすくみが中間値として出る。
- 側面写真なしの評価で、側面系要訣が「未評価」と表示される。
- 検出失敗時に評価値が一切出力されない。

## 11. 段階的開発計画

| フェーズ | 内容 |
|----------|------|
| Phase 1 | A・B・C 基準の静止画評価（キャリブレーション含む）。CLI。 |
| Phase 1.5 | **D 系の予備実験**: 体に沿った服・側面/背面撮影で、骨盤くぼみ・含胸・抜背がシルエットから判別可能か検証。不能なら SMPL 系メッシュ復元への移行判断。 |

| Phase 4 | 複数カメラ三角測量による3D化（回旋の直接測定。Pose2Sim 等）。 |

## 付録A: 判定の表現例

| タイプ | 表示例 |
|--------|--------|
| A OK | 立身中正: OK（傾き1.2度） |
| A 要修正 | 墜肘: 要修正 — 右肘がめくれて横を向いています（外向き78度） |
| B 注意 | 虚実分明: 注意 — 重心がやや後ろです（前6:後4 / 規定 前7:後3） |
| C | 沈肩: 注意 — 右肩にすくみが出ています（すくみ率35%） |
| D | 骨盤の立ち: 普段より立てられています（くぼみ−18%）。緩めすぎの判定は先生の確認を。 |
| 測定不能 | 墜肘: 測定不能 — 腕が伸びているため向きを判定できません |
| 未評価 | 虚実分明: 未評価 — 側面写真が必要です |

## 付録B: v1.0 からの主な変更

- 計測モデルを A/B/C/D の4タイプに分類（v1.0 は全要訣をお手本基準で設計）
- 预备式＋怒らせ肩によるセッション毎2点キャリブレーションを導入
- 墜肘を B から A へ移動し、角二等分線による肘向き測定と閾値（45/70度）・測定不能条件（肘角160度超）を定義
- 対象套路を制定套路に確定（B 基準の一次基準を規定値とする）
- 対象学習者の前提条件（预备式が成立していること）と品質ゲートを追加
- D 系の服装ルール・予備実験フェーズ（Phase 1.5）・SMPL 系への移行判断を追加
- 墜肘↔沈肩の相関セルフチェックを追加
