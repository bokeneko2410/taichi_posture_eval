# 姿勢比較プロトタイプ 仕様書（ドラフト v0.1）

太極拳の演者写真を解析し、お手本（先生）との姿勢の違いを関節角度で比較するためのツール群。SPLYZA Motion のようなマーカーレス動作解析の発想を、静止画ベース・軽量・自作で実現することを狙う。

---

## 1. 目的・背景

SPLYZA Motion 等のマーカーレス3D動作解析に着想を得て、「精密でなくてよいので、運動している人の写真から軸や骨格を推定し、複数演者の姿勢を比較したい」という発想が出発点。

最終的にやりたいことは **太極拳の複数演者の静止画を撮り、お手本（先生）と各演者のフォームを比較する** こと。何がどれだけ違うのかを関節単位で定量化し、指導や自己点検に使える形にする。

## 2. スコープ / 非スコープ

| 区分 | 内容 |
|------|------|
| スコープ | 静止画1枚からの単一人物の姿勢推定。関節角度の算出。お手本基準での差分比較。骨格の重ね描きと差分の可視化。 |
| 非スコープ（現段階） | 動画・時系列解析、複数人同時検出、精密な3D復元、リアルタイム処理、関節角度の医学的・力学的な正確性保証。 |
| 将来的に検討 | 複数カメラによる三角測量での3D化（Pose2Sim 等）、前額面・矢状面の併用、お手本の許容範囲（平均±標準偏差）判定。 |

## 3. 用語

- **ランドマーク**: 姿勢推定モデルが返す身体上の特徴点（肩・肘・膝など）。BlazePose では33点。
- **関節角度**: ある関節を頂点とし、隣接2点へのベクトルが成す角度。体格・カメラ距離に依存しない比較用の特徴量。
- **お手本（reference）**: 比較の基準となる先生の姿勢データ。
- **visibility**: モデルが返すランドマークの可視度（0–1）。低い点を含む角度は信頼できない。
- **体幹軸**: 両肩の中点と両尻の中点を結ぶ線。鉛直からの傾きで姿勢の傾きを表す。

## 4. 全体構成（処理フロー）

処理の流れは添付の `posture_compare_flow.drawio` を参照（VSCode の draw.io 拡張で表示）。概略は次のとおり。

1. お手本・各演者の写真を、それぞれ `pose_angles.py` に通して関節角度JSONに変換する。
2. お手本JSONを基準に、`pose_compare.py` が各演者JSONとの差分を算出する。
3. 出力として、関節別ズレのテキストレポートと、骨格重ね描き＋差分バーの比較図（PNG）を得る。

各ツールは標準入出力で連結できる Unix フィルタ志向で設計し、途中のJSONを目視・`awk` 等で再利用できるようにする。

## 5. コンポーネント仕様

### 5.1 `pose_angles.py` — 画像 → 関節角度JSON

- **入力**: 画像ファイル（`-i` 指定）または標準入力のバイナリ画像。
- **処理**: MediaPipe Pose Landmarker（Tasks API, IMAGE モード, `num_poses=1`）で33ランドマークを検出。指定した関節の角度を、x/yをピクセル換算した2D座標から内積で算出する。
- **出力**: 関節角度・visibility・体幹傾き・正規化ランドマークを含むJSON（標準出力）。`-o` 指定で注釈付き画像も保存。
- **備考**: 角度は「カメラに写った2D投影面での角度」。奥行き方向は含まない。モデルファイル（`pose_landmarker.task`）は初回実行時に自動ダウンロードする。

### 5.2 `pose_compare.py` — お手本と各演者の比較

- **入力**: `--ref` でお手本JSON、続けて演者JSONを複数。
- **処理**: 関節ごとに `演者角度 − お手本角度` を符号付きで算出。お手本・演者いずれかの visibility が閾値（既定0.5）未満の関節は信頼不可として警告し、総合スコアから除外する。
- **出力**: 関節別差分のテキストレポート（ズレの大きい順）、信頼できる関節のRMSによる総合ズレ、お手本から遠い順のランキング。`--figdir` 指定で演者ごとの比較図PNG（左=骨格重ね描き、右=差分バー）を出力。

### 5.3 `pose.py` — 初期プロトタイプ（骨格＋軸の可視化）

最初に作った単体ツール。画像を標準入力で受け、骨格と体幹軸を描いた注釈画像を標準出力へ、傾き等の解析値を標準エラーへ出す。比較機能は持たないが、検出と軸の感触を掴む用途として保持する。

## 6. データ仕様（角度JSONスキーマ）

`pose_angles.py` の出力JSON。

| キー | 型 | 内容 |
|------|----|------|
| `detected` | bool | 人物を検出できたか |
| `source` | string | 入力元（ファイル名または "stdin"） |
| `image_size` | [int, int] | 画像の[幅, 高さ]（px） |
| `angles` | object | 関節名 → 角度（度）。検出不能は null |
| `visibility` | object | 関節名 → 信頼度（0–1, 構成3点の最小値） |
| `trunk_tilt_deg` | float | 体幹軸の鉛直からの傾き（度, 0=直立, 正=肩が右へ） |
| `landmarks` | object | ランドマーク番号 → [x, y, visibility]（正規化座標） |

## 7. 測定する関節と角度の定義

各関節は「端A – 頂点B – 端C」の3点で定義し、頂点Bを挟む角度を測る（BlazePose の番号）。

| 関節名 | A | B（頂点） | C |
|--------|---|-----------|---|
| left_elbow | 左肩(11) | 左肘(13) | 左手首(15) |
| right_elbow | 右肩(12) | 右肘(14) | 右手首(16) |
| left_shoulder | 左肘(13) | 左肩(11) | 左尻(23) |
| right_shoulder | 右肘(14) | 右肩(12) | 右尻(24) |
| left_hip | 左肩(11) | 左尻(23) | 左膝(25) |
| right_hip | 右肩(12) | 右尻(24) | 右膝(26) |
| left_knee | 左尻(23) | 左膝(25) | 左足首(27) |
| right_knee | 右尻(24) | 右膝(26) | 右足首(28) |

加えて体幹傾き（trunk_tilt_deg）を全体の姿勢指標として算出する。

## 8. 比較方式（お手本基準）

- お手本を1つの基準とし、各演者を1対多で比較する。
- 関節ごとの差分は符号付き（`演者 − お手本`）。正＝お手本より角度が大きい（曲げすぎ／開きすぎ）、負＝小さい傾向、と読む。
- 総合ズレは、信頼できる関節の差分のRMS（二乗平均平方根）。
- 可視化は、ヒップ中点を原点・肩中点〜尻中点距離を1として正規化した骨格を、お手本（グレー）と演者（赤）で重ね描きする。これにより体格差を吸収して形の違いだけを見る。

## 9. 前提・制約

- **撮影条件の統一が精度の大半を決める**。全演者を同じ向き・同じ距離・全身がフレームに収まる構図で撮る。
- 単一視点のため奥行き方向の情報は失われる。弓歩の踏み込み深さや体の回旋など、奥行きに関わる要素は正確に測れない。
- 角度はあくまで2D投影面の値であり、医学的・力学的な絶対精度は保証しない。あくまで相対比較・傾向把握の道具。
- 1枚に1人を前提（`num_poses=1`）。

## 10. 既知の課題 / 今後の拡張

- 奥行き対応: 横からの写真も撮り、前額面・矢状面で別々に比較する。本格的には複数カメラ＋三角測量（Pose2Sim）で3D化する。
- お手本の許容範囲: 複数のお手本写真から関節ごとの平均±標準偏差を作り、そこを外れた関節だけ強調表示する。
- 測定項目の追加: 首の傾き、足首、左右対称性の指標など。
- 左右反転（鏡像）フォームの対応: 比較前に一方をミラーリングする選択肢。
- レポート形式: CSV/JSON出力を整備し、Obsidian や表計算で集計しやすくする。

## 11. 動作環境・依存

- 端末: Mac（Apple Silicon）想定。
- Python: 3.12 系を推奨（MediaPipe の対応状況に依存）。
- 依存パッケージ: `mediapipe`, `opencv-python`, `numpy`, `matplotlib`。
- 図表示: draw.io フォーマット（`.drawio`）、VSCode の draw.io 拡張で閲覧。

## 付録: 実行例

```sh
pip install mediapipe opencv-python numpy matplotlib

# 1) お手本と各演者を JSON 化
./pose_angles.py -i teacher.jpg    > teacher.json
./pose_angles.py -i performer1.jpg > p1.json
./pose_angles.py -i performer2.jpg > p2.json

# 2) お手本基準で比較し、比較図も出力
./pose_compare.py --ref teacher.json p1.json p2.json --figdir ./out
```
