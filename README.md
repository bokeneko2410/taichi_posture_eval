# 太極拳姿勢評価プログラム
### マーカーレス姿勢推定による自主練習支援ツール（開発中）

---

## 何を作っているか

太極拳の自主練習で、キーポーズの写真を撮影するだけで、
**要訣（動作の指導ポイント）ごとに姿勢を評価し、お手本との差を
指導の言葉で返す**ツール。

マーカーも専用機材も不要。スマホ1台＋Mac で動く。

```
撮影(スマホ) → 姿勢抽出(MediaPipe) → 要訣ごとの評価 → フィードバック
「右肘がめくれて横を向いています（外向き78度）」
「重心がやや後ろです（前6:後4 / 規定 前7:後3）」
```

---

## 開発の背景と動機

SPLYZA Motion のようなマーカーレス3D動作解析ツールに着想を得た。

太極拳を学んでいく上で、自主練習での客観的な確認手段がないことが
長年の課題だった。先生に毎回見てもらえるわけではないし、
ビデオや鏡では自分の感覚と求められる定式とのズレや要訣の充足度を正確には把握できない。
「自分で撮った写真から、指導の言葉に近いフィードバックを返すツールを自分で作ろう」というのが出発点。

設計を進める中で、既製の姿勢推定ツールでは満たせない要件に気づいた。

- 関節角度の数値は、要訣と結びついていない
- 「沈肩（肩を沈める）」の評価は他人との角度比較ではなく、
  **自分が肩を上げた状態からどれだけ落とせたか**が指標になる
- 本当に知りたいのはその日の評価より、**稽古を重ねる日々の改善の推移**

これらを正しく設計するために、技術仕様を繰り返し書き直した。

## 技術的なポイント

### 計測モデルの4分類

要訣の性質に応じて、比較の基準を4タイプに分けた。

| タイプ | 基準 | 例 |
|--------|------|----|
| A 構造基準 | 幾何学的に絶対評価 | 膝がつま先を越えていないか |
| B お手本基準 | 制定套路の規定＋お手本の許容範囲 | 弓歩の後ろ脚の角度 |
| C 保持型 | 自分の基準姿勢からの変化 | 沈肩（肩のすくみ率） |
| D 変化型 | 自分の習慣的緊張からの解放量 | 骨盤の立ち・含胸 |

C・D は「他人と比べる」のではなく「自分の体の癖から出発する」。
この分類が、修練の文脈で意味のある評価を設計する核心だった。

### 墜肘（肘の向き）の測定

MediaPipe の33ランドマークには「肘の向き」が存在しない。
肩・肘・手首の3点から、**角の二等分線の逆ベクトル**として肘頭の向きを
幾何学的に復元し、鉛直下向きからの外向き角で評価する。
腕がほぼ伸びている場合は「原理的に測定不能」として誤値を出さない設計。

### データ設計: 生値一次主義

評価の閾値（例: 肘外向き45度以内=OK）は運用調整パラメータとして分離し、
JSONL には**生の測定値だけを追記**する。
閾値を変えても過去データから再計算できる。
モデルを更新したとき写真から全履歴を再抽出できる。
「後から正しく比べられる」ことを設計の前提にした。

### 解析エンジンの設計方針

評価したいことは毎回変わる——今日のスナップショット、
数ヶ月の推移、あの日との比較、お手本との比較。
これを「機能別に別々のプログラムを作る」ではなく、

```
評価 = 対象セレクタ(--target) × 基準セレクタ(--vs)
```

という2軸の照合エンジンとして設計した（実装予定）。
新しい比べ方は「比較器」を1つ追加するだけで足せる。
